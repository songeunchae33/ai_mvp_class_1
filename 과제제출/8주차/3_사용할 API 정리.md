# 사용할 API 정리 — 나만의 경제

- 확인한 날짜: **2026-11-03** (1·2번은 2026-11-09) (공식 주소를 이날 열어 확인)
- 키 값은 적지 않았어요. 값은 모두 Vercel 환경 변수에만 있어요.

---

## 1) 주가·지수 시세

1. **무엇을:** 홈을 열면 코스피·코스닥 지수와 내 관심 종목의 전일 종가가 타일로 나와요.
2. **어느 API:** 지수는 한국은행 경제통계시스템(ECOS) Open API · https://ecos.bok.or.kr/api/ (통계 802Y001 주식시장(일)) / 관심 종목은 공공데이터포털 금융위원회_주식시세정보 · https://www.data.go.kr/data/15094808/openapi.do
3. **키:** 필요함 · ECOS 홈페이지에서 인증키 신청(`ECOS_KEY`), 공공데이터포털 가입 후 주식시세정보 '활용신청'(`DATA_GO_KR_KEY`) · 둘 다 서버에 둘 키
4. **밖으로 나가는 정보:** 관심 종목 이름(예: 삼성전자)과 조회 날짜 · 실제 사람의 정보 없음

## 2) 원/달러 환율

1. **무엇을:** 홈의 '오늘, 나에게 미치는 영향'에 환율과 '1,000달러 환전하면 얼마 더 드는지'가 나와요.
2. **어느 API:** 한국은행 경제통계시스템(ECOS) Open API · https://ecos.bok.or.kr/api/ (통계 731Y001 주요국 통화의 대원화환율, 원/미국달러 매매기준율)
3. **키:** 필요함 · 1번과 같은 `ECOS_KEY` · 서버에 둘 키
4. **밖으로 나가는 정보:** 조회 날짜만 · 실제 사람의 정보 없음

## 3) 우리 지역 혜택

1. **무엇을:** '우리 지역 혜택' 화면에서 사는 곳을 고르면 그 지역의 지자체·정부 혜택 목록이 나와요.
2. **어느 API:** 공공데이터포털 행정안전부_대한민국 공공서비스(혜택) 정보 · https://www.data.go.kr/data/15113968/openapi.do
3. **키:** 필요함 · 공공데이터포털에서 이 API도 '활용신청'(1번과 같은 `DATA_GO_KR_KEY`) · 서버에 둘 키
4. **밖으로 나가는 정보:** 시·도 또는 시·군·구 이름, '청년'·'대학생' 같은 찾을 단어 · 실제 사람의 정보 없음 (나이·관심사는 보내지 않고 우리 서버에서 거르는 데만 씀)

## 4) 내 위치로 동네 찾기

1. **무엇을:** 홈·우리 지역 혜택·마이페이지에서 '내 위치로 찾기'를 누르고 위치를 허용하면 시·도와 시·군·구가 저절로 채워져요.
2. **어느 API:** 네이버 클라우드 Maps Reverse Geocoding · https://api.ncloud-docs.com/docs/application-maps-reversegeocoding
3. **키:** 필요함 · 네이버 클라우드 플랫폼 콘솔 → Maps → Application 등록(Reverse Geocoding 체크)해서 받은 Client ID·Client Secret(`NAVER_MAP_CLIENT_ID`, `NAVER_MAP_CLIENT_SECRET`) · 서버에 둘 키
4. **밖으로 나가는 정보:** 휴대폰 위치 좌표(약 100m 단위로 뭉갠 값) · 실제 사람의 정보 있음(위치). 이름 등 다른 정보는 함께 보내지 않고, 좌표는 저장하지 않아요.

## 5) 경제 뉴스

1. **무엇을:** 홈 '뉴스'와 뉴스 화면에 오늘의 이슈, 내 관심 종목 관련 뉴스 제목과 링크가 나와요.
2. **어느 API:** 네이버 클라우드 NAVER API HUB 뉴스 검색 · https://www.ncloud.com/product/applicationService/naverApiHub
3. **키:** 필요함 · 네이버 클라우드 플랫폼 콘솔 → NAVER API HUB → Application 등록(검색)해서 받은 인증 정보(`NAVER_HUB_ID`, `NAVER_HUB_SECRET`) · 서버에 둘 키
4. **밖으로 나가는 정보:** 검색어(관심 종목 이름, 경제 키워드) · 실제 사람의 정보 없음

## 6) 정부 보도자료

1. **무엇을:** 공부의 '이번 주 화제 TOP 5'와 뉴스의 '쉽게 풀이'에 쓰는 정부 보도자료 제목·본문을 가져와요.
2. **어느 API:** 공공데이터포털 문화체육관광부_정책브리핑 정책뉴스 · https://www.data.go.kr/data/15095335/openapi.do
3. **키:** 필요함 · 공공데이터포털에서 이 API도 '활용신청'(1번과 같은 `DATA_GO_KR_KEY`) · 서버에 둘 키
4. **밖으로 나가는 정보:** 조회 기간(날짜)만 · 실제 사람의 정보 없음

## 7) 루미의 AI 설명 (질문 답변·쉽게 풀이·뉴스레터 풀이·가계부 캡처 읽기)

1. **무엇을:** 검색창에 질문하면 루미가 쉬운 말로 답하고, '쉽게 풀이'·뉴스레터 붙여넣기 풀이를 보여 주고, 가계부에 카드·은행 앱 캡처를 올리면 소비 내역을 읽어 기록해요.
2. **어느 API:** Google Gemini API 무료 등급을 먼저 쓰고(https://aistudio.google.com/docs/pricing , 2026-11-09), 무료 한도를 넘거나 실패하면 OpenAI API(https://platform.openai.com/docs/guides/your-data)로 넘어가요.
3. **키:** 필요함 · Gemini는 aistudio.google.com → Get API key에서 발급(`GEMINI_API_KEY`, 결제 연결 안 함), OpenAI는 platform.openai.com → API keys에서 발급(`OPENAI_API_KEY`) · 둘 다 서버에 둘 키
4. **밖으로 나가는 정보:** 질문 글, 붙여넣은 뉴스레터 글, 정부 보도자료, 관심사, 나이대·투자 성향·소득 구간·자산·대출 금액 요약, 가계부 캡처 사진과 소비 요약 · 실제 사람의 정보 있을 수 있음. 닉네임·이름은 보내지 않지만, 캡처 사진에는 가게 이름·금액·날짜가 있고 화면에 이름이나 카드번호 일부가 보일 수 있어요. Gemini 무료 등급은 보낸 내용을 구글이 서비스 개선에 쓸 수 있어요(https://aistudio.google.com/docs/pricing , 2026-11-09).

## 8) 기기 연결 (구글 로그인)

1. **무엇을:** '기기 연결'에서 구글로 로그인하면 다른 휴대폰에서도 내 프로필·가계부·공부 기록을 이어 써요.
2. **어느 API:** Google Firebase (Authentication, Firestore) · https://firebase.google.com/support/privacy
3. **키:** 필요함 · Firebase 콘솔 → 프로젝트 설정 → 웹 앱 설정값(`FIREBASE_API_KEY` 등 4개) · 페이지에 넣는 키(비밀 키가 아닌 공개 설정값)
4. **밖으로 나가는 정보:** 구글 계정 이메일·이름, 이 앱의 기록 전체(프로필·자산·가계부·공부 기록) · 실제 사람의 정보 있음(이메일, 소비 기록)
