# 나만의 경제 PRD v0.5

2026-10-15 기준 · 원본: Claude 문서 「나만의 경제 PRD v0.5」를 저장소 기록용으로 옮긴 것

## 개요

나만의 경제는 내 자산·성향·관심사에 맞춰 경제 정보를 한 화면에 모아 '나에게 어떤 의미인지'까지 알려주는 2030용 웹앱이다. v0.5는 실제 데이터로 동작하는 MVP 단계다.

| 항목 | 내용 |
| --- | --- |
| 버전 | v0.5 (MVP, 실제 데이터 연동 완료) |
| 배포 | [aimvpclass1.vercel.app](https://aimvpclass1.vercel.app) |
| 형태 | 모바일 우선 웹앱 (바닐라 JS 한 페이지 + Vercel 서버 함수) |
| 저장 | 개인정보는 사용자 기기(브라우저)에만 저장, 서버 DB 없음 |

**해결하려는 문제**: 머니레터·뉴닉 같은 뉴스레터는 메일로 따로 읽어야 하고, 포털·금융앱의 시세·뉴스는 누구에게나 똑같다. '내 대출, 내 여행 계획, 내 관심 종목에 오늘 무슨 일이 생겼는지'를 한눈에 보여주는 서비스가 없다.

## 목표

사용자가 매일 아침 앱을 열어 1분 안에 '오늘 내 돈과 관련된 경제 소식'을 파악하고, 경제 개념을 조금씩 배우게 하는 것이 목표다.

1. **한눈에**: 지수·환율·관심 종목·뉴스·일정을 홈 화면 한 곳에, 긴 내용은 더보기로.
2. **나에게 맞춰**: 같은 숫자도 내 대출·선호·목표·지역으로 번역해서 보여준다.
3. **배우게**: 매일 OX 퀴즈와 쉬운 풀이로 2030의 금융 이해도를 높인다.
4. **내 돈 기록**: 캡처 한 장으로 소비를 기록하고 피드백을 받는다.

**성공 지표 (베타 기준, 목표치는 미정)**

| 지표 | 뜻 |
| --- | --- |
| 7일 뒤 재방문율 | 매일 열 이유가 있는가 |
| 퀴즈 연속 기록 평균 일수 | 배우는 습관이 생기는가 |
| 주간 소비 기록 비율 | 가계부 기능을 계속 쓰는가 |
| 프로필 완성도 | 맞춤 정보를 만들 재료가 충분한가 |

## 대상 사용자

핵심 사용자는 경제 뉴스레터를 구독하지만 따로 찾아 읽기는 버거운 20~34세 대학생·사회초년생이다.

| 사용자 | 상황 | 필요한 것 |
| --- | --- | --- |
| 대학생 (20대 초반) | 용돈·알바, 예금 위주, 주식은 소액 | 우리 지역·학교 혜택, 쉬운 경제 개념, 여행·쇼핑 생활비 영향 |
| 사회초년생 (20대 중후반) | 월급, 첫 대출·적금, 목표 저축 | 금리 변화가 내 이자에 주는 영향, 소비 기록·피드백, 청년 정책 |
| 관심 종목 보유자 | 포털·증권앱을 따로 확인 | 내 종목 시세와 뉴스를 한 곳에, 보유 수량 기준 손익 |

사용 상황은 출근·등교길 아침 1분 확인과 주 1회 소비 기록이다. 뉴스레터 구독자(머니레터·뉴닉)가 첫 타깃이다.

## 기능

v0.5는 하단 탭 4개(홈 / 공부 / 나의 자산관리 / 가계부)와 마이페이지, 기타로 나뉘며, 아래 기능이 모두 배포돼 있다. 목차는 마이페이지 / 홈 화면 / 경제공부 / 나의 자산관리 / 가계부 / 기타 순서로 묶는다.

| 위치 | 기능 | 내용 |
| --- | --- | --- |
| 마이페이지 | 내 정보 | 기본 정보(닉네임·나이·소득·지역·학교), 투자 성향(7문항 진단), 저장하기 |
| 홈 | 루미 말풍선 브리핑 | 나를 위한 경제 정보: 시장 분위기, 내 종목 등락, 환율 영향, 일정·혜택 알림을 한 문장씩 (루미가 코스피 분위기대로 움직임) |
| 홈 | 시세 한 줄 | 코스피·코스닥·원/달러·관심 종목(전일 종가), 옆으로 넘기기 |
| 홈 | 오늘, 나에게 미치는 영향 | 환율→여행·직구 비용, 금리→내 대출 이자, 보유 종목 평가액 변화 |
| 홈 | 뉴스 | 오늘의 이슈 1 + 나를 위한 뉴스 1 + 키워드, 더보기는 쉬운 풀이 먼저 |
| 홈 | 나를 위한 일정·우리 지역 혜택 | 관심사별 일정(오늘·내일만 홈에), 지역·나이·상황별 혜택 |
| 홈 | 오늘의 OX 퀴즈 | 매일 한 문제, 연속 기록 |
| 홈 | 상단 검색·홈 화면 꾸미기 | 앱 안 검색 + 루미에게 AI 질문, 칸 순서·숨김 |
| 공부 | 경제 개념·퀴즈 | 개념 40개·7주제, 화제순·최신순·오답순·가나다순, 복습·내 노트·연속 기록 |
| 공부 | 뉴스 쉽게 풀이·뉴스레터·관심 종목 | 정부 정책뉴스 AI 풀이, 뉴스레터 붙여넣기 풀이·구독 관리, 종목 추가·순서·보유 수량 |
| 나의 자산관리 | 순자산·자산 진단 | 자산·대출 입력, 구성 비율, 부채비율·비상금·성향 대비 투자 비중 진단 |
| 나의 자산관리 | 목표 저축 | 만/억 단위, 2056년까지, 매달 모을 금액 계산 |
| 가계부 | 내 돈 기록 | 이용내역 캡처(최대 8장) AI 자동 분류, 직접 기록, 주간·월간 요약, 루미 피드백 |
| 기타 | 개인정보·앱 정보 | 루미 움직임 켜기·끄기, 내 정보 전체 삭제, 데이터 출처 |

첫 설문은 루미와 함께 3단계(닉네임·나이 → 관심 종목 → 성향·선호·뉴스레터)로 짧게 하고, 대출·지역·상황·소득·월급날은 홈의 맞춤 질문 카드가 하나씩 묻는다. 앱을 열 때 루미 로딩 화면을 최소 0.7초 보여준다.

## 원칙

두 가지 제품 원칙을 우선하고, 법·약관·개인정보 규칙은 예외 없이 지킨다.

**제품 원칙**

1. **홈은 짧게, 자세한 건 더보기**: 홈은 한눈에, 긴 내용은 더보기·옆으로 넘기기·별도 화면으로.
2. **모든 정보는 '나에게 어떤 의미'까지**: 숫자만 보여주지 않고 내 대출·선호·목표·지역으로 번역한다.

**반드시 지킬 것**

- 특정 종목 매수·매도 추천 금지(투자자문업 규제). 진단은 '참고용 일반 기준'으로만.
- 데이터 기준 시점과 출처를 항상 표시한다.
- 네이버 검색 결과는 제목+링크로 '그대로 보여주기'만. AI 요약은 공공저작물(정책브리핑)이나 사용자가 붙여넣은 글로만.
- 구글 뉴스 RSS는 개인 피드 리더 전용 약관이라 쓰지 않는다.
- 다른 앱의 로고·이름·고유 그래픽은 따라 하지 않는다.

**개인정보·비용**

- 프로필·자산·목표·가계부·퀴즈 기록은 브라우저에만 저장하고 서버에 모으지 않는다. AI에는 요약값만 보낸다(닉네임 제외). 캡처 사진은 읽기에만 쓰고 저장하지 않는다.
- 유료 서비스는 가입·결제하지 않는다. OpenAI 비용이 드는 기능은 만들기 전에 비용과 함께 확인한다. 캡처는 하루 20장으로 제한한다.

## 이번 주 기능

- **기능**: AI 사용 한도 — 루미에게 물어보기·뉴스레터 풀이·가계부 캡처 읽기를 하루 정해진 횟수까지만 쓴다.
- **누가**: 앱을 쓰는 모든 사용자, 그리고 OpenAI 비용을 내는 운영자.
- **무엇을**: 하루 질문 20번, 뉴스레터 풀이 5번, 캡처 20장까지 쓰고, 남은 횟수를 보여주며, 다 쓰면 루미가 "내일 다시 물어봐 주세요"라고 안내한다.
- **완료 기준**: 한도를 넘기면 AI를 부르지 않고 안내 문구가 뜨며, 다음 날 다시 쓸 수 있다.

## 앞으로 계획

다음 단계는 v0.5를 마무리하고 10~30명 베타로 '매일 여는가'를 확인하는 것이다. 돈이 드는 장중 시세와 프로 모드는 그 뒤로 미룬다.

로드맵 (기간은 정하지 않았고, 앞 단계의 결과를 보고 다음 단계로 넘어간다)

1. **v0.5 마무리 (지금)**: AI 사용 한도·백업, 메뉴 재배치·앱 설치
2. **베타 (10~30명)**: 재방문·사용 지표 측정, 인터뷰로 우선순위 결정
3. **계정·동기화**: 간편 로그인·서버 저장, 개인정보 동의·암호화
4. **데이터 고도화**: 장중 시세(유료 검토), 가격·지역 혜택 알림
5. **프로 모드** (관문: 법률 확인): 시나리오 계산기, 주간 리포트·AI 무제한
6. **정식 출시**: 사업자·통신판매업 신고, 앱스토어·결제 연동

**프로 모드 (구독)**: 무료로도 충분히 쓸 만하게 두고, '나한테 돈이 되는 기능'으로 차별화한다. 후보는 금리·환율 시나리오 계산기, 주간 맞춤 리포트, AI 질문 무제한, 가격 알림, 광고 제거다. 수익 모델은 프로 구독 + 맨 위 작은 광고 배너(아직 없음)다.
