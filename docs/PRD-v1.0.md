# PRD v1.0

## 1. 문제

머니레터·뉴닉 같은 뉴스레터는 메일로 따로 읽어야 하고, 포털·금융앱의 시세·뉴스는 누구에게나 똑같다. '내 대출, 내 여행 계획, 내 관심 종목에 오늘 무슨 일이 생겼는지'를 한눈에 보여주는 서비스가 없다.

## 2. 고객

핵심 사용자는 경제 뉴스레터를 구독하지만 따로 찾아 읽기는 버거운 20~34세 대학생·사회초년생이다. 사용 상황은 출근·등교길 아침 1분 확인과 주 1회 소비 기록이다. 뉴스레터 구독자(머니레터·뉴닉)가 첫 타깃이다.

## 3. 불편의 크기

- 발생 빈도: 하루에 1회 이상 — 경제 뉴스·정보를 찾기 위해 네이버 앱에 들어가 직접 웹 검색함
- 현재 대안의 실패율/소요시간: 검색 결과는 누구에게나 같아 내가 원하는 정보를 바로 받아볼 수 없음 — 검색에 하루 10분 정도 소요(추정치)
- 포기 시 손실: 나의 지출과 수입에 대해 지속적으로 피드백을 받을 플랫폼이 없어 소비 점검을 놓침 — 손실 금액은 추정치 없음(모름)

## 4. 핵심 가치

나만의 경제는 내 자산·성향·관심사에 맞춰 경제 정보를 한 화면에 모아 '나에게 어떤 의미인지'까지 알려주는 2030용 웹앱이다.

## 5. 핵심 흐름

사용자가 매일 아침 앱을 열어 1분 안에 '오늘 내 돈과 관련된 경제 소식'을 파악하고, 경제 개념을 조금씩 배우게 하는 것이 목표다. 첫 설문은 루미와 함께 3단계(닉네임·나이 → 관심 종목 → 성향·선호·뉴스레터)로 짧게 하고, 대출·지역·상황·소득·월급날은 홈의 맞춤 질문 카드가 하나씩 묻는다.

## 6. 지금 있는 것

- 누르자마자 - 사전질문을 통해 나에 대한 기본 정보 얻게 됨(맞춤형 정보 제공을 위해) 마이페이지-기본정보 입력 및 수정 가능
- 홈 화면-주요 지수 정보 제공, 나에게 미치는 영향 요약, 오늘의 뉴스, 다가오는 일정 및 혜택 확인 가능
- 공부 화면-이번 주 화제 top5 뉴스 확인 가능, 경제 용어 관련 퀴즈 풀이 가능
- 나의 자산관리 화면-나의 자산/목표 저축/나의 자산진단에서 지출과 수입, 투자를 바탕으로 한 분석 가능
- 가계부 화면-쓴 돈 캡처로 기록 및 통계 볼 수 있음, 루미에게 지출 피드백 받을 수 있음
- 목차 =다양한 탭/기능 한 번에 모아볼 수 있음

## 7. 점검에서 걸린 것과 바꿀 것

점검(처음 온 사람 · 버튼과 링크 · CLAUDE.md 대조)에서 걸린 것 → 바꾼 것

- 홈 뉴스가 '예시' 기사로 나옴(네이버 사용량 한도 초과) → 뉴스를 1시간 저장해 호출을 줄이고, 예시 문장의 틀린 환율 숫자를 뺌
- 닉네임 예시에 실제 사람 이름이 들어감 → '경제새싹'으로 바꿈
- '내 정보 전부 지우기'를 해도 가계부·공부 기록·AI 사용 횟수가 남음 → 모두 지우게 함
- 홈에 들어오기만 해도 AI 풀이가 자동으로 불림(비용) → '쉽게 풀이'를 눌렀을 때만 만들게 함
- 첫 설문: 앱 이름과 하는 일 소개가 없음, 뉴스레터가 처음부터 선택됨, 나이를 묻는 이유·'종목'·투자 성향 설명이 없음 → 소개 말풍선 고침, 기본 선택 없앰, 설명 추가
- 홈: 0% 움직였는데 '가장 크게 움직였어요'가 뜸, '관망' 설명 없음, 마지막 말풍선에서 처음으로 못 돌아감 → 문구 고침, '처음으로' 버튼 추가
- 뉴스레터 풀이에 짧은 글을 넣어도 하루 횟수가 깎임, 추가해도 안내가 없음 → 횟수 안 깎음, 안내 문구 추가
- 가계부 기록 삭제에 확인 창 없음, 공부 탭을 바꾸면 펼친 개념이 접힘, 일정 화면 안내 위치가 틀림 → 확인 창 추가, 펼침 유지, '나의 자산관리'로 고침
- CLAUDE.md 화면 설명이 실제 화면과 다름(관심 종목 순서 위치 등) → 실제 화면에 맞게 고침

## 8. 이번 주 기능

- **기능**: AI 사용 한도 — 루미에게 물어보기·뉴스레터 풀이·가계부 캡처 읽기를 하루 정해진 횟수까지만 쓴다.
- **누가**: 앱을 쓰는 모든 사용자, 그리고 OpenAI 비용을 내는 운영자.
- **무엇을**: 하루 질문 20번, 뉴스레터 풀이 5번, 캡처 20장까지 쓰고, 남은 횟수를 보여주며, 다 쓰면 루미가 "내일 다시 물어봐 주세요"라고 안내한다.
- **완료 기준**: 한도를 넘기면 AI를 부르지 않고 안내 문구가 뜨며, 다음 날 다시 쓸 수 있다.

## 9. 다음 기능

다음 단계는 v0.5를 마무리하고 10~30명 베타로 '매일 여는가'를 확인하는 것이다. 돈이 드는 장중 시세와 프로 모드는 그 뒤로 미룬다.

1. **v0.5 마무리 (지금)**: AI 사용 한도·백업, 메뉴 재배치·앱 설치
2. **베타 (10~30명)**: 재방문·사용 지표 측정, 인터뷰로 우선순위 결정
3. **계정·동기화**: 간편 로그인·서버 저장, 개인정보 동의·암호화
4. **데이터 고도화**: 장중 시세, 가격·지역 혜택 알림
5. **프로 모드** (관문: 법률 확인): 시나리오 계산기, 주간 리포트·AI 무제한
6. **정식 출시**: 사업자·통신판매업 신고, 앱스토어·결제 연동

## 10. 안 할 것

- 특정 종목 매수·매도 추천 금지(투자자문업 규제). 진단은 '참고용 일반 기준'으로만.
- 네이버 검색 결과는 제목+링크로 '그대로 보여주기'만. AI 요약은 공공저작물(정책브리핑)이나 사용자가 붙여넣은 글로만.
- 구글 뉴스 RSS는 개인 피드 리더 전용 약관이라 쓰지 않는다.
- 다른 앱의 로고·이름·고유 그래픽은 따라 하지 않는다.
- 유료 서비스는 가입·결제하지 않는다.
